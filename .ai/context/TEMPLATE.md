# Context pack — AI-XXX

> Crie um destes **apenas** quando ele evitar exploração repetida numa task complexa ou de vários passos.
> Não crie para toda task. Uma correção de uma linha não precisa de context pack.

## Objetivo

Uma ou duas frases. O que estará verdadeiro quando a task terminar.

## Arquivos relevantes

Caminho e por que ele importa. Se souber a linha, cite a linha.

## Docs relevantes

Só os que a task realmente exige.

## Decisões relevantes

ADRs que a task pode contrariar.

## Restrições

O que não pode mudar, e por quê.

## Riscos conhecidos

Onde isso costuma dar errado. O que a validação não vai pegar.

## Validação

Como saber que funcionou — incluindo verificação manual quando os comandos não bastam.

## Fora de escopo

O que **não** fazer nesta task, mesmo parecendo próximo. Isto é o campo que mais economiza tempo.
