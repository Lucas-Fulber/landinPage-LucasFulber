# Sessões recentes

Memória fria. **Não leia por hábito** — só quando precisar investigar por que algo ficou como ficou.

Nome: `AAAA-MM-DD--AI-XXX--descricao-curta.md`

Registre só sessão significativa. Correção de uma linha não precisa de registro; a task e o Git já contam a história.

Conteúdo: task, resultado, achados importantes, decisões, validação, follow-ups. Curto.

**Não copie:** diff, saída de terminal, arquivo inteiro. O Git já guarda o histórico técnico — o registro de sessão guarda o que o Git não mostra: o porquê, o que foi descartado, e o que quase deu errado.

Quando passar de 10 arquivos, compacte conforme `.claude/rules/memory.md`.
